## Запуск проекта (5 минут)

1. Запустите Docker:
```
   docker-compose up -d
```

2. Откройте http://localhost:5678

3. Импортируйте workflow:
   - Нажмите "Import from File"
   - Выберите RAG_polling_google.json

4. Настройте credentials (из файла .env):
   - Telegram Trigger → кликните на credential → New → вставьте TELEGRAM_BOT_TOKEN
   - Send Telegram Response → выберите тот же Telegram credential
   - Groq Chat Model → New → вставьте GROQ_API_KEY
   - Embeddings HuggingFace → New → вставьте HUGGINGFACE_TOKEN
   - Google диск ссылка

5. Активируйте workflow (переключатель Active в правом верхнем углу)

6. Готово! Отправьте боту /index в Telegram

7. Далее отправляйте вопросы
